About TranslaAI

TranslaAI is a multilingual translator built to explore the core building blocks of a modern AI product: Natural Language Processing, API integration, and a clean, responsive interface. The project pairs a lightweight Flask backend with a hand-built frontend to demonstrate how a real-world translation tool comes together, end to end.
